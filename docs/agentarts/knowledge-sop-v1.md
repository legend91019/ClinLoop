# ClinLoop 合成流程连续性知识库 v1

用途：仅用于合成病例的工作流跟进教学与比赛演示。不是诊疗指南，不提出诊断、处方或治疗建议。

## 随访意图

当临床记录明确要求“某项检验结果回报后查看、通知、复核或确认”时，存在结果随访意图。仅有检验医嘱或检验结果、没有对应随访要求时，不创建此意图。若文字含糊，保留不确定性并请人工核对。

## 结果与确认

检验结果到达，不等于医生已查看。确认必须是明确关联该结果的临床记录。缺少确认记录，只能称“在已搜索记录中未找到确认”，不能断言医生没有实际查看。

## 来源校验

证据必须指向当前患者、就诊、触发事件时间之前已可见的记录。不得猜测事件 ID、检验编号或引用未来记录。不同检验项目不可互相代替：血培养随访意图不能由代谢面板结果完成。

## 安全边界

模型只建议工作流候选和只读查询。证据核对、状态流转由 ClinLoop Guard 执行；医生负责接受或驳回待审核缺口与交班封存。模型不得自行写病历、关闭任务、诊断、开药、对患者发送消息。
